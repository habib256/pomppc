POMPPC @VERSION@ for Windows x64 (experimental)

Keep this folder together and double-click POMPPC.exe. Your disks and settings live in
%USERPROFILE%\POMPPC. The assistant takes you from an empty disk to a running system.

Requirements: 64-bit Windows 10 1903 or newer, and an OpenGL driver for your graphics card.
Windows may warn that this program isn't signed; choose "More info" then "Run anyway".

This package has been built and tested by a machine without a graphics card, a sound card or a screen.
Running Mac OS X on real Windows PCs hasn't been proven yet: what is known and what isn't is in
https://github.com/habib256/pomppc/blob/@VERSION@/docs/publier-windows.md
